1. VISÃO GERAL DO QUE FOI IMPLEMENTADO
================================================================================

Foi criada uma camada completa de inteligência para análise e métricas da 
frota de navios, utilizando heurísticas simples baseadas em regras de negócio.
Esta camada permite:

- Calcular risco de bioincrustação de navios
- Analisar ROI (Retorno sobre Investimento) de limpezas
- Agregar métricas consolidadas da frota
- Identificar navios críticos que precisam de atenção
- Estimar economia potencial com manutenção preventiva

================================================================================
2. ARQUIVOS CRIADOS
================================================================================

2.1. backend/app/services/calculations.py
-----------------------------------------
Este arquivo contém as funções principais de cálculo:

A) calculate_fouling_risk(idle_days, water_temp, salinity)
   - Calcula o risco de bioincrustação (0-100)
   - Considera:
     * Dias que o navio ficou parado (cada dia = +5 pontos)
     * Temperatura da água (temp > 25°C = +15, temp > 20°C = +5)
     * Salinidade da água (salinidade > 35 = +5)
   - Categoriza o risco: baixo (<30), moderado (30-69), crítico (≥70)
   - Retorna: {"risk": int, "level": str}

B) calculate_cleaning_roi(avg_fuel_consumption, optimized_consumption, 
                          fuel_price_per_ton, days)
   - Calcula quanto dinheiro pode ser economizado com uma limpeza
   - Compara consumo atual vs consumo otimizado
   - Multiplica pela diferença, período e preço do combustível
   - Retorna: {"extra_fuel_tons": float, "savings_money": float}

C) aggregate_fleet_metrics(logbooks, fuel_price)
   - Processa múltiplos navios e agrega os dados
   - Para cada navio:
     * Calcula risco usando calculate_fouling_risk()
     * Identifica navios críticos (risco ≥ 70)
     * Calcula desperdício de combustível usando calculate_cleaning_roi()
   - Calcula média de risco da frota
   - Soma todo o desperdício e economia potencial
   - Retorna JSON consolidado com todas as métricas

2.2. backend/app/services/data_service.py
------------------------------------------
Este arquivo simula a busca de dados do banco de dados:

A) get_recent_logbooks(days=30)
   - Retorna lista de logbooks mockados (simulando dados reais)
   - Cada logbook contém:
     * ship_id: ID do navio
     * ship_name: Nome do navio
     * idle_days: Dias parado
     * water_temp: Temperatura da água
     * salinity: Salinidade
     * avg_fuel_consumption: Consumo médio atual
     * optimized_consumption: Consumo otimizado esperado
     * last_maintenance_date: Data da última manutenção

   NOTA: Em produção, esta função faria uma consulta SQL ao banco de dados
         real, buscando logbooks dos últimos N dias.

2.3. backend/app/api/v1/endpoints/dashboard.py
-----------------------------------------------
Endpoint REST para expor as métricas:

A) GET /api/v1/dashboard
   - Parâmetros opcionais:
     * days: Número de dias para analisar (padrão: 30)
     * fuel_price: Preço do combustível por tonelada (padrão: 3500.0)
   
   - Fluxo interno:
     1. Busca logbooks recentes via get_recent_logbooks()
     2. Processa dados via aggregate_fleet_metrics()
     3. Retorna JSON estruturado com todas as métricas
   
   - Validações:
     * days deve estar entre 1 e 365
     * fuel_price deve ser maior ou igual a 0
     * Tratamento de erros com mensagens descritivas

   - Calcula média de riscos
   - Categoriza nível geral da frota

PASSO 5: Retorno
   - Valida dados com Pydantic (DashboardMetrics schema)
   - Retorna JSON estruturado para o frontend

6. DETALHES TÉCNICOS DAS HEURÍSTICAS
================================================================================

6.1. Cálculo de Risco de Bioincrustação
----------------------------------------
FÓRMULA:
   risk = 20 (base)
   + (idle_days × 5)  [cada dia parado aumenta risco]
   + 15 se water_temp > 25°C
   + 5 se 20°C < water_temp ≤ 25°C
   + 5 se salinity > 35
   risk = max(0, min(100, risk))  [garante entre 0-100]

POR QUÊ ESSAS REGRAS?
- Navios parados: Acúmulo de organismos sem movimento da água
- Temperatura alta: Acelera metabolismo de organismos marinhos
- Salinidade: Diferentes espécies preferem diferentes salinidades

6.2. Cálculo de ROI de Limpeza
--------------------------------
FÓRMULA:
   extra_per_day = avg_consumption - optimized_consumption
   extra_tons = extra_per_day × days
   savings = extra_tons × fuel_price_per_ton

POR QUÊ?
- Bioincrustação aumenta arrasto hidrodinâmico
- Maior arrasto = mais combustível necessário
- Limpeza reduz arrasto = reduz consumo

No frontend, você pode usar assim:

TYPESCRIPT:
-----------
const API_URL = import.meta.env.VITE_API_URL || 'http://localhost:8000/api/v1';

async function getDashboardMetrics(days = 30) {
  const response = await fetch(`${API_URL}/dashboard?days=${days}`);
  const data = await response.json();
  return data;
}

// Uso
const metrics = await getDashboardMetrics(30);
console.log(`Risco médio: ${metrics.fleet_average_risk}%`);
console.log(`Economia potencial: R$ ${metrics.total_savings_money}`);
